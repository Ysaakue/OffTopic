# offtopic

Flutter app of OffTopic, a hands-free group voice room for motorcycle riders
over a local Wi-Fi hotspot. See the repository [CLAUDE.md](../CLAUDE.md) and
[docs/](../docs/) for architecture, rules and commands.

```powershell
fvm flutter run            # on a connected Android phone
../tools/verify.ps1        # every check of the workspace
```
