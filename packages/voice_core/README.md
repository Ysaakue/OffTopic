# voice_core

C++17 voice core of OffTopic (audio capture/playback, processing, Opus, jitter
buffer, mixing, network) and its Dart FFI client.

- C API: [`include/voice_core.h`](include/voice_core.h)
- Core sources: `src/`; GoogleTest suite: `tests/`; desktop presets: `CMakePresets.json`
- Dart client: `VoiceCoreClient` / `FfiVoiceCoreClient`; test double: `package:voice_core/testing.dart`
- Bindings: `lib/src/generated/voice_core_bindings.g.dart`, regenerated by `../../tools/codegen.ps1`

No audio sample ever crosses into Dart.
