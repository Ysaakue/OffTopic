# voice_platform

Typed platform services of OffTopic — foreground service, audio route, Wi-Fi
binding, system settings — implemented in Kotlin (Android) and Swift (iOS,
phase 7) through Pigeon.

- Channel definition: [`pigeons/voice_platform_api.dart`](pigeons/voice_platform_api.dart), regenerated by `../../tools/codegen.ps1`
- Dart API: `VoicePlatformGateway` and its narrow interfaces; `PigeonVoicePlatformGateway`
- Test double: `package:voice_platform/testing.dart` (`FakeVoicePlatformGateway`)
- Android sources and tests: `android/src/main/kotlin`, `android/src/test/kotlin`

No audio sample ever crosses these channels.
